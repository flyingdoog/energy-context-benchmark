# Code and data availability

Code and data for the paper accepted at the IEEE International Conference on
Computer & Applications 2026:

> Code, evaluation scripts, aggregate results, and prepared EPFL and CU-BEMS
> forecasting data are available at
> https://github.com/flyingdoog/energy-context-benchmark. Original code is
> released under the MIT license. Third-party data retain their source licenses
> and attribution. For BPA and ACN-Data, the repository provides source access
> and preparation instructions rather than redistributing the records.

The [v1.0.0 release](https://github.com/flyingdoog/energy-context-benchmark/releases/tag/v1.0.0)
provides `context-energy-forecasting-data-v1.0.0.zip` alongside the code asset;
CU-BEMS arrays are not committed to Git. The manuscript PDF and LaTeX sources
are not included. The repository documents the existing experiments; this
release does not claim a new independent training replication.
