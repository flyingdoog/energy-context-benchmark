# Archived experimental implementations

These files preserve the implementation context for the already completed
Ridge, LightGBM, N-HiTS, declarations, and record-reassignment studies. They
are copied from the original workspace. Missing local helper imports were
included during release preparation; no training experiment was rerun.
The original result-directory conventions are retained. They are not a
one-command portable retraining package.

For portable source preparation, input views, prediction submissions, scoring,
and the default four-arm tree comparison, use the parent `code/scripts/` and
`code/docs/RECORD_COMPARISON_RUNTIME.md`. Acquire source records and prepare
packets using the source guides or the EPFL/CU-BEMS public data asset. ACN donor
records are not included. Adapt archived paths to your local directories;
the root [reproduction guide](../../docs/REPRODUCING.md) explains the distinction
between the portable runtime and historical experiment entries.

For the reported measurements, read the CSV/JSON files in the root `results/`
directory. Their correspondence to the paper is listed in the reproduction
guide. Manuscript PDF, LaTeX sources and typesetting tools are not included.
